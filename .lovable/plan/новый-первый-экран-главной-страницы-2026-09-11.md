# Новый первый экран главной страницы

Полностью переработать верхнюю часть главной страницы (заголовок «Токены, акции и облигации Беларуси — в одном кабинете», подзаголовок, кнопки, строка цифр) в современном стиле финансовых платформ — плотнее по вертикали, удобнее на телефоне.

## Что не так сейчас

- Центрированный блок на светло-синем градиенте: на десктопе широкие пустые поля слева и справа, много воздуха сверху и снизу.
- Заголовок в три строки на телефоне, кнопки растянуты на всю ширину друг под другом — первый экран занимает почти весь телефон, и до цифр рынка нужно долго листать.
- Строка «2 500+ компаний · 2 400+ акций · …» — мелкий текст, на телефоне ломается на несколько строк и читается плохо.
- Общая подача выглядит как типовой шаблон, а не как финансовый продукт.

## Новый первый экран

Двухколоночная композиция на десктопе вместо центрированного текста:

```text
Десктоп (>=1024px)
+---------------------------------------------------------------+
| Токены, акции и облигации   |  [ карточка «Рынок сейчас» ]     |
| Беларуси — в одном кабинете |  250+ токенов   700+ облигаций   |
| подзаголовок, 2 строки      |  2 400+ акций   2 500+ компаний  |
| [Открыть дашборд] [Портфель]|  4 площадки: Finstore, Bynex,    |
| площадки · обновлено сегодня|  Fainex, Whitebird               |
+---------------------------------------------------------------+

Мобильный (<640px)
+-----------------------------+
| маленький бейдж «Беларусь»  |
| Заголовок (2-3 строки)      |
| Короткий подзаголовок       |
| [ Открыть дашборд ]  (шир.) |
| [ Создать портфель ] (шир.) |
| 2x2 сетка цифр рынка        |
+-----------------------------+
```

Ключевые решения:

- **Слева — смысл, справа — цифры.** Текст и кнопки в левой колонке, живые показатели рынка — в компактной карточке справа. Пустое место на широких экранах уходит, экран сразу выглядит «рабочим».
- **Меньше воздуха.** Вертикальные отступы секции сокращаются примерно на треть; блок «Рынок Беларуси сегодня» ниже перестаёт дублировать цифры (три большие карточки убираем, оставляем заголовок раздела со ссылками на полную статистику).
- **Цифры вместо строки-перечисления.** На телефоне четыре показателя выстраиваются в сетку 2×2 с крупными числами — читаемо и без переносов.
- **Кнопки.** На телефоне обе на всю ширину, высота не меньше 48 px; на десктопе — в ряд, основная синяя, вторая — контурная.
- **Современная подача.** Тёмная глубокая подложка в фирменной сине-графитовой гамме с мягким свечением, вместо бледного голубого градиента; тонкая сетка/линии как на финансовых терминалах; крупная плотная типографика Manrope; аккуратные скругления и лёгкая анимация появления цифр.
- **Бейдж доверия** над заголовком: «Данные 4 площадок Беларуси · обновляется ежедневно».
- Подзаголовок сокращается до одной ёмкой фразы, чтобы на телефоне не занимать три строки.

## Что остаётся неизменным

- Текст заголовка H1 и ключевые слова — без изменений (важно для поиска).
- Ссылки на дашборд и портфель, разметка для поисковых систем, счётчики аналитики.
- Все секции ниже первого экрана, кроме удаления дублирующих карточек с цифрами.

## Технические детали

- Правки только в `index.html`, секция Hero (строки ~244-338) и вложенный Alpine-компонент `marketStats()`.
- Разметка: `<section>` c `grid lg:grid-cols-[1.1fr_0.9fr] gap-8 items-center`, контейнер `max-w-6xl`, паддинги `py-10 sm:py-14 lg:py-16`.
- Цифры карточки продолжают питаться из `marketStats()` — SSR-значения остаются в HTML, чтобы краулеры читали их без JS.
- Тёмная подложка задаётся через существующие HSL-токены/утилиты Tailwind; никаких новых зависимостей, никакого JS сверх уже подключённого Alpine.
- Контраст текста на тёмном фоне проверяем по AA (>= 4.5:1); тап-таргеты >= 44 px; `h1` остаётся единственным на странице.
- Порядок DOM: текст → кнопки → карточка цифр, чтобы на мобильном ничего не переставлять через `order`.
- Dataset JSON-LD для показателей рынка сохраняем, при переносе цифр обновляем `url`-якорь на новый идентификатор секции.
