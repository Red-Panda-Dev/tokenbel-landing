# Вход в личный кабинет

Войдите через социальные сети, чтобы получить максимум от сервиса TokenBel.

## Способы входа

- Google
- Telegram
- Яндекс
- Microsoft

Инструкция по регистрации и входу: https://wiki.tokenbel.info/guides/rukovodstvo-polzovatelia/

## Преимущества личного кабинета

- **Быстрые уведомления** — мгновенные оповещения через Telegram-бота.
- **Избранные токены и компании** — быстрый доступ к интересным эмиссиям.
- **Персональный календарь** — сроки и выплаты избранных эмиссий в одном месте.
- **Вторичный рынок** — уведомления о новых предложениях по избранному.
- **Персональная RSS-лента** — обновления в удобном формате.
- **Формирование портфеля** — состав, доходность, HHI, энтропия, коэффициент рычага.
- **Акции белорусских компаний** — каталог 2 400+ акций: тикер, эмитент, тип бумаги, номинал, объём выпуска.
- **Облигации с купонным календарём** — 700+ выпусков: ставка, периодичность выплат, дата погашения, оферта, YTM, история сделок.

Подробнее о личном кабинете: https://wiki.tokenbel.info/
