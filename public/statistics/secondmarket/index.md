# Статистика вторичного рынка токенов Беларуси

Интерактивные графики строятся по данным API TokenBel (https://hype.tokenbel.info/) и обновляются автоматически.

## Разделы статистики

- Распределение по платформам и операциям (покупка / продажа).
- Операции по платформам и типам.
- Топ токенов по количеству предложений.
- Топ компаний по количеству предложений.
- Всего операций по дням.
- Операции по платформам по дням.

Источники данных: площадки Finstore, Bynex, Fainex, Whitebird.

Актуальные значения графиков доступны в HTML-версии страницы https://tokenbel.info/statistics/secondmarket/ и через API https://hype.tokenbel.info/.
